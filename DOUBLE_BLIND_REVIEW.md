# Double-blind review checklist

The project page is currently written for anonymous review. Before making it public or linking it from a submission, audit these items:

- Keep author names, affiliations, personal URLs, email addresses, lab names, grants, and acknowledgments out of the page, metadata, favicon, and social preview image.
- Do not link to a repository, personal homepage, institutional page, preprint, code release, or supplementary material that identifies the authors.
- Replace `Anonymous authors` and the anonymous conference label only after the review period.
- Remove or anonymize filenames, alt text, figure labels, and captions that mention a lab, robot platform owner, institution, or private dataset path.
- Recheck the paper and assets for comments or draft text that expose contributors. The LaTeX source currently contains a commented list of author names.
- Do not publish the unfinished architecture draft, placeholder experiment images, pending percentages, or TODO-marked tables as evidence of final results.

The current page intentionally omits the author list, affiliations, repository links, funding, unfinished assets, and unfilled result claims.
